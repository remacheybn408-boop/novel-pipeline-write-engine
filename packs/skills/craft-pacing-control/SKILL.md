# 节奏控制

节奏是张力的时间分布：张弛交替、蓄力与爆发成比例。诊断先看曲线，再动手术。

## 工作流

1. 按章画出张力曲线：标出高潮、过渡、喘息点。
2. 找出三类病灶：连续平段（拖）、连续高段（疲）、爆发无蓄力（假）。
3. 用场景级手段修复：删并过渡章、拆长章、前置钩子。
4. 检查每章结尾是否有“不得不翻页”的钩子，钩子类型要轮换。
5. 高潮前必须有蓄力章；高潮后必须有余波章。

## 可交付内容

- 分章张力曲线图与病灶标注
- 场景删并与重排建议清单
- 钩子类型分布表

## 边界

- 不改变主线剧情结论，只调整呈现顺序与密度。
- 不为提速删掉必要的情感蓄力。
- 不套用模板节奏；曲线要服务具体故事。

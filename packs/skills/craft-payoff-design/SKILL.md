# 爽点设计

爽点是压抑与释放的差价：先让读者替主角憋屈，再让释放超出预期。爽点类型要轮换，单一口味会腻。

## 工作流

1. 列出爽点类型库：实力碾压、打脸、解密、情感确认、身份揭示、复仇。
2. 设计压抑—释放比：憋屈要具体、可共情，释放要成比例。
3. 排布节奏：小爽高频（章级）、中爽卷级、大爽篇级，类型不重复连用。
4. 爽点必须由主角的选择触发，不靠天降巧合。
5. 爽后留余味：给出新目标或新代价，避免爽完即弃。

## 可交付内容

- 爽点类型分布表与压抑—释放配比图
- 关键爽点场景的铺垫链设计
- 爽感疲劳风险诊断

## 边界

- 不为爽降智反派或破坏世界观一致性。
- 主角获利要有成本与后果，不开无限金手指。
- 不抄袭已知作品的标志性爽点桥段。

# 张爱玲技法卡

张爱玲最值得迁移的是意象统摄的叙事结构与"参差对照"的美学：用一个核心意象（月亮、镜子、香炉）开篇定调、结尾回扣，用精准而冷峭的比喻切开人物心理，不写壮烈写苍凉，让不彻底的小人物在时代的褶皱里现形。

## 核心手法

1. **意象框定全篇**：以一个意象开篇、同一意象收束，意象的物理变化（月升月沉）即人物命运的暗线。何时用：中短篇，需要凝练的环形结构。写法示例：以三十年前的一轮月亮起笔，结尾让月亮沉下去，而故事"还没完——完不了"。
2. **远取譬比喻术**：比喻的本体与喻体距离拉得很远，靠感知上的神似一击即中，新奇而不重复。何时用：人物亮相、心理定格的瞬间。写法示例：写一个人的笑，不说"灿烂"，说那笑像一件搁久了的瓷器，拿出来时还带着灰。
3. **参差对照**：不用善恶的斩钉截铁，而用葱绿配桃红式的错位配色——可怜与可鄙、精明与天真并置一身。何时用：写复杂的普通人、避免扁平人物。写法示例：让刻薄的女主角在算计一生的间隙，露出一个少女时代的手势。
4. **苍凉手势**：在情感高点不写哭喊，写一个姿态、一个动作的细节，以姿势定格命运。何时用：结局、诀别、幻灭时刻。写法示例：不写她多绝望，只写她把镯子捋下来、又缓缓推回去的那个手势。
5. **心理白描**：用极省的一两句直陈人物心底的真实盘算，冷静到残忍。何时用：人情冷暖、亲密关系里的暗流。

## 叙事声音与节奏

第三人称全知，叙述者声音聪明、世故、带讥讽的怜悯，时时跳出一句断语点破人物。时间多为回忆框架（"三十年前"），首尾环扣。节奏张弛分明：场景铺陈华丽绵密，转折处一刀切断，华丽与冷峭交替。

## 对白与细节

对白是攻防战：客套话里藏刀，每句都有潜台词与心理价位。细节是服饰、器物、颜色、光线的精密调度，物质细节直指心理与阶层。意象系统完整而现代：月亮、镜子、玻璃、香炉、胡琴声，古老物象被赋予现代心理内涵。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

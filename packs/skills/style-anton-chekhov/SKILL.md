# 安东·契诃夫技法卡

契诃夫最值得迁移的是短篇的经济学：客观冷静的叙述撤走作者表情，靠一两个功能细节立起整个人物，结尾骤停在生活继续的地方，把判断权完整交给读者。

## 核心手法

1. **客观冷叙**：剔除叙述中的主观色彩，只写行动与对话，悲剧场面也保持体温不变，情绪由读者自行生成。何时用：哀伤、荒诞题材反而要克制时。写法示例：亲人去世的那晚，只写当事人如何讨药、如何走夜路，不写一句悲痛。
2. **功能细节（枪原则）**：出现的每个细节必须开工——第一章挂出的枪，后文一定要响；不响的枪不许挂。何时用：修订阶段做减法。写法示例：开头写巡官两次穿脱大衣，后文他每次变脸都伴随一次穿脱。
3. **小道具塑人**：用一件不起眼的物件浓缩人物的全部性格与处境。何时用：短篇篇幅内快速立人。写法示例：临终的老匠人念念不忘的，是答应给人做的一个烟盒——执念、技艺与卑微全在里面。
4. **对比反转**：让同一个人物在短时段内反复改口、变调，反转的次数本身就是批判。何时用：讽刺题材。写法示例：小官对一条狗的态度五分钟内翻转三次，每次都依据主人是谁。
5. **骤停结尾**：故事在情绪刚要收拢处停笔，不升华、不解释、不圆满，让余味发生在文本之外。何时用：短篇收尾。写法示例：吵了一辈子的两个人刚露出和解迹象，镜头停在其中一人伸手去关灯。

## 叙事声音与节奏

第三人称全知但温度极低，叙述者与人物保持距离，不代言、不辩护。时间取生活的一个横切面，几乎无闪回；节奏平缓，无高潮设计，靠细节累积产生压强。短篇的推进逻辑是"状况"而非"事件"——不是事情如何了结，而是处境如何显形。

## 对白与细节

对白日常、琐碎、答非所问，人物很少说出真心话，真意藏在没说出的部分。细节精确、可感、有气味——两种食物的气味就能交代两个人的两种阶级，且全部承担功能。意象系统清淡：雪、灯、路、套子式的封闭物，偶尔一个意象收束全篇。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

# 自传与回忆录小说

记忆是素材，反思是结构。自传体小说的核心不是"发生了什么"，而是"多年之后的叙述者如何理解发生了什么"。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先定叙述者站在何时回望：回望的距离决定语调与评判的宽容度。
2. 把一生切成若干"记忆锚点"——具体场景、气味、一句话，而非编年流水账。
3. 每个锚点按"当年经验—今日反思"双层写，让两个时态的自己对话。
4. 苦难与缺憾不美化、不诉苦，写出它如何塑造了后来的人。
5. 检查每章是否有超越个人经历的普遍意义，否则删或并。

## 可交付内容

- 生命阶段表、记忆锚点清单、双层叙事（经验/反思）安排
- 关键场景：转折、告别、顿悟、和解
- 真实性边界说明（哪些是事实、哪些经过虚构加工）

## 边界

- 不消费真实他人的隐私与伤痛；涉及在世人物要做虚构化处理。
- 不把回忆录写成控诉书或功劳簿；叙述者对自己同样诚实。
- 避免编年体流水账；按意义而非时间取舍材料。

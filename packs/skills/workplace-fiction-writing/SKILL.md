# 职场小说

专业细节是信任的门槛，博弈是剧情的燃料。升职不是目标本身，人物想成为什么样的人才算。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先定行业与岗位的真实工作流程，再定主角的核心项目。
2. 建立利益地图：上司、平级、下属、客户各自要什么。
3. 冲突按“任务—阻力—博弈—胜负—余波”推进，输赢都要符合职场逻辑。
4. 金手指克制：主角靠专业判断与信息差赢，不靠降智对手。
5. 检查每章是否有职业选择背后的人格选择。

## 可交付内容

- 行业流程卡、利益关系图、项目线和卷纲
- 提案、谈判、背锅或翻盘场景
- 行业细节可信度诊断

## 边界

- 不使用真实公司、真实人物或可识别的行业事件。
- 不使用已知职场剧的情节骨架。
- 不把潜规则当卖点；人物底线要清晰。

# 武侠小说

武学是价值观的动作化表达；江湖是人情债、名声与权力的网络。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先给主角一道无法两全的侠义难题，再设武力与关系的双重阻力。
2. 建立江湖名声如何传播、承诺如何兑现、背叛如何付出代价。
3. 读取 `references/blueprint.md`，确定门派利益、师承裂缝和招式逻辑。
4. 动作场景按“意图—试探—变化—代价—余波”写，不堆砌招式名。
5. 检查胜负是否改变人物对承诺、仇恨或自由的理解。

## 可交付内容

- 江湖势力表、侠义命题、恩怨链和卷纲
- 决斗、护送、追查或师门对峙场景
- 招式系统与战斗可读性诊断

## 边界

- 不使用已知武侠作品的角色、武功、门派、地名或情节骨架。
- 不能只以武力决定道德正当性。
- 避免把暴力浪漫化；交代伤势、后果和关系余震。

规划时读取 `references/blueprint.md`；真正写正文、改文风或诊断节奏前，必须先读取 `references/craft.md`；写分章、连载或卡文修复时，读取 `references/chapter-engine.md`。

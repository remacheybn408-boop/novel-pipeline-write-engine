# 耽美小说

情感靠选择推进，不靠误会拖延。张力来自身份、立场与欲望的错位，而非单纯的身体描写。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先定两位主角各自的缺口与执念，让彼此成为对方的解药与考验。
2. 设计关系阶段：对立—试探—默契—危机—确认，每步要有事件支撑。
3. 糖与刀交替供给，甜要有代价，虐要有出口。
4. 亲密场景服务于情感确认，节奏克制、留白得当。
5. 检查每个情感节点是否由人物主动选择触发。

## 可交付内容

- 人物缺口表、关系阶段图、名场面清单和卷纲
- 对峙、守护、坦白或和解场景
- 情感节奏诊断

## 边界

- 不使用已知作品的角色、名场面或情节骨架。
- 不靠巧合与误会硬拖剧情。
- 尊重 consent；不把控制欲浪漫化。

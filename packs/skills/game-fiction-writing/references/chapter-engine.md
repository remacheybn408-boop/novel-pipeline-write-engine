# 游戏章节生成引擎

## 选择本章模式

| 模式 | 用于 | 核心写法 |
|---|---|---|
| 对局章 | 比赛、副本、排位 | 读者先知道胜负条件 |
| 复盘章 | 失败、训练、争执 | 让技术问题暴露关系问题 |
| 赛季章 | 排名与成长 | 每次胜负改变资源或信任 |

## 1,500 字章节配比

`150 字目标与局面 → 350 字计划 → 500 字变数和协作 → 300 字关键判断 → 200 字结果与现实余波`。

## 常见失败与替换

- 失败：连续技能报数。替换：写技能解决的战术问题和付出的资源。
- 失败：主角独秀。替换：让队友的信息、失误和选择决定战局。
- 失败：输赢无后果。替换：让排名、合同、队内信任或自尊发生变化。

## 出章门槛

读者能复述本局的胜负原因，以及它如何改变角色关系。

# 游戏小说写作技法

## 叙述声音

- 速度快但不混乱。每个关键操作前让读者知道目标、位置、资源与风险。
- 游戏内术语要从人物判断中自然出现；第一次出现时给功能和限制。
- 在高光之外写复盘、疲劳、队友沉默和现实压力，使胜负有重量。

## 场景语法

`赛前目标/副本任务 → 执行计划 → 对手或系统变数 → 信息更新与协作 → 胜负 → 现实关系余波`。

## 段落与节奏

- 开战前短句交代局面，中段用因果串起操作，关键时刻再压缩句子。
- 每回合只强调一个战术问题，避免连续报技能和数值。
- 交替写“屏幕上发生什么”与“角色为何做此判断”。

## 修订检查

不玩游戏的读者能否理解胜负原因？若不能，补目标和限制；避免引用现实游戏的专有内容。

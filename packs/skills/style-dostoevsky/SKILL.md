# 陀思妥耶夫斯基技法卡

陀氏最值得迁移的是复调的组织法：让人物各自成为独立、平等、不相融合的声音，作者放弃终审权，把"思想"变成情节的真正主角，用对话把形而上冲突写出惊悚级的悬念。

## 核心手法

1. **思想人格化**：给每个主要人物分配一个"伟大而未解决的思想"，让人物被思想支配、为思想行动，情节冲突即观念冲突。何时用：需要智力纵深的严肃长篇。写法示例：三兄弟各信一种活法，每次家庭聚会都是三种世界观相撞。
2. **全面对话**：对话不止于情节功能，人物的话总是同时针对"事"和"另一个人的话"而发（双声语），连独白都在与想象中的对手辩论。何时用：写争论、自白、审讯。写法示例：罪人没说出口的辩护，在他对每个人的寒暄里暗中进行。
3. **共时性展开**：不给人物前史缓冲，把行为直接摆在"此时此刻"，靠同一时空内的对峙而非因果链条推进。何时用：高压场面、危机时刻。写法示例：重要人物一出场就处在情绪顶点，他的过去靠争吵中的互相揭短补全。
4. **人群聚拢术**：把立场冲突的人物强行聚拢在一个房间（宴席、葬礼、探视），让矛盾在同一场景内连环引爆。何时用：章节高潮设计。写法示例：一场接风宴安排五个互有旧怨的客人，每道菜上桌都炸开一桩往事。
5. **作者悬置判断**：叙述者不替任何人物下最终定论，善的声音与恶的声音获得同等修辞力量，裁判权交给读者。何时用：道德灰区题材。写法示例：反派的陈词写得比主角的反驳更有逻辑，让读者先被说服、再被震动。

## 叙事声音与节奏

第三人称，配一个近乎在场记者的叙述者：琐碎、急切、偶尔自嘲，贴着事件喘气。时间压缩在几天甚至几小时内，靠延宕（关键信息迟迟不给）制造灼热悬念。节奏是痉挛式的：长段对话的紧绷，与突发事件（病发、闯入、丑闻爆发）的骤断交替。

## 对白与细节

对白是全书引擎：亢奋、跳跃、自我打断，人物在说话中暴露比他们想说的更多的东西。细节服务于象征与生理感：气味、发黄的脸色、楼梯间的黑暗。意象系统围绕深渊与救赎：楼梯、十字路口、孩子、梦境，在最暗的段落投下微弱光源。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

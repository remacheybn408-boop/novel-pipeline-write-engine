# 格非技法卡

格非最值得迁移的是"叙述空缺"的悬念诗学与时间悬空术：在情节的关键节点故意留白，让读者在缺口处自行补完；用首尾循环与重复打破线性时间，把偶然性写成命运的形状，并以书卷气的抒情语言将先锋形式接入古典传统。

## 核心手法

1. **关键信息空缺**：情节链上最重要的一环（一次会面、一个人的下落）始终不写，空缺本身成为叙事的发动机。何时用：悬疑氛围、命运不可知主题。写法示例：写一场决定生死的约会，前后都写，唯独约会本身缺席，人物从此活在它的阴影里。
2. **首尾循环结构**：结尾回到开头的场景或语句，时间呈闭环，暗示宿命与重复。何时用：写轮回感、历史的重演。写法示例：开篇主人公在渡船上望向对岸，结尾他再次站在同一条船上，人事已非而河水如旧。
3. **重复与变奏**：同一事件在不同视角或不同时间被再度叙述，每次透露新的缺口。何时用：真相的多义性、记忆的不可靠。写法示例：一桩失踪由三个人各讲一遍，三版互相矛盾，真相在矛盾之间。
4. **时间悬空**：切断故事与历史观念的黏连，让事件漂浮在"何时发生都可以"的氛围里。何时用：写存在的偶然性、去历史化的抒情。写法示例：只给节令与光影，不给年份与大事记，让一段爱情悬在时间之外。
5. **多层构思法**：动笔前同时构思七八层——故事、人物、情感、社会关系、细节、余意——成书内容远超"想表达的"。何时用：长篇规划阶段。

## 叙事声音与节奏

第三人称为主，声音清冷、克制、书卷气浓，抒情描写常盖过情节推进，形成"后悲剧"的苍凉调子。时间非线性，预叙、追叙、循环交错，时钟故意失灵。节奏缓慢迂回，靠氛围与悬念的雾气而非事件的速度抓人。

## 对白与细节

对白雅洁含蓄，人物说话常绕开正题，言在此而意在彼。细节写意多于写实：江南的雨、花、阁楼、乌篷船，物象皆带追忆的光泽。意象系统古典化：桃花、河流、梦、雪，与古典诗词互文，先锋的形式装着古典的魂。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

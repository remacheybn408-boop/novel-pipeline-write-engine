# 克苏鲁与规则怪谈

恐怖来自不可知与规则缝隙：知道得越多，越接近疯狂；规则越详细，违背的代价越具体。创作必须独立，公有领域神话元素可用，但须原创组合。

## 工作流

1. 先定“真相”只露冰山一角：读者与主角同步拼图，不同步全知。
2. 规则怪谈先写规则清单，再设计哪条是真、哪条是饵、哪条自相矛盾。
3. 调查按“异常—线索—逼近—失控—幸存或堕落”推进。
4. 恐怖场景用感官细节与逻辑违和，少用血腥直给。
5. 检查恐怖是否指向更大的未知，而非一次性惊吓。

## 可交付内容

- 规则清单与真伪表、调查线索链、神话谱系和卷纲
- 异常记录、守则、目击报告或档案体文本
- 恐怖节奏与规则自洽诊断

## 边界

- 不照搬已知神话作品的具体角色、实体名或情节骨架。
- 规则不可随意推翻；违背规则的后果要一致。
- 避免纯血腥堆砌；疯狂与未知才是核心。

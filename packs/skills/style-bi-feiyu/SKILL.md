# 毕飞宇技法卡

毕飞宇最值得迁移的是"贴着人物写"的叙事力学：章节以人物命名、视角随人轮转，叙述者以夹叙夹议的点评切开人物内心，外部情节极度压缩，把全部势能压进自尊、欲望与权力的细微搏动里，短促、冷静、一刀见血。

## 核心手法

1. **人物中心结构**：章节直接以人物命名，每章贴着一个人的视角与命运走，群像靠章节轮转换位完成。何时用：群像戏、机构/行业题材。写法示例：写一家小店，十章各以一个伙计为圆心，同一事件在不同章节里呈现不同温度。
2. **叙议结合的点评刀**：叙述中突然插入一两句叙述者的断语，把人物没说出口的心思点破，果断不留余地。何时用：心理暗战、人情微妙处。写法示例：人物赔笑之后补一句——他笑得越周到，心里的账算得越清。
3. **外部压缩、内部放大**：删减事件铺陈，把篇幅让给一次握手、一个眼神里的权力流动。何时用：不靠情节靠心理推进的段落。写法示例：一场谈判不写条款，只写谁先把茶杯推远了半寸。
4. **尊严驱动冲突**：让人物的核心欲望落在"被承认"上，一切行动由自尊的得失驱动。何时用：塑造有劲道的人物，尤其是压抑中的普通人。写法示例：让失势的父亲在女儿婚礼致辞的座次上做文章，小事写出坍塌。
5. **特殊感知视角**：借盲人、病人等感官受限者的知觉方式重写世界，逼迫读者换一种感知。何时用：想给庸常场景陌生化的新意。

## 叙事声音与节奏

第三人称为主但叙述者存在感强，介乎一二三人称之间，寒凉又滚烫：隔岸观火的冷静里透出切肤的体恤。时间顺叙，跨度不大。节奏短促凶猛，句子短、断语快，段落之间留白多，靠心理压强而非情节密度抓人。

## 对白与细节

对白经精心镂刻，每人一副腔口，贴合身份又极锋利，对话常是不见刀光的攻防。细节取人情世故的微妙处——座次、称呼、谁先伸手——一个细节即一场战争。意象不重，力量全在人际的力学里。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

# 列夫·托尔斯泰技法卡

托尔斯泰最值得迁移的，是"心灵辩证法"：不写人物转变的结果，而写转变的螺旋过程本身；以及在史诗框架里保持日常颗粒度的能力——战役与客厅共用同一套描写逻辑。

## 核心手法

1. **心灵辩证法**：让人物在全书跨度内不断自我否定、螺旋上升，出场时与结局时判若两人，且每一步变化都写得可追溯。何时用：长篇人物弧光。写法示例：军官的功名心在三次战场、两场爱情中逐层剥落，每次他都以为自己找到了终极答案。
2. **两大板块交替**：用战争/和平、城市/乡村这类二元结构交替推进，两边互为镜子——客厅里也有战役，战场上也有客厅式的琐碎。何时用：史诗型长篇的框架搭建。写法示例：社交季的婚姻攻防写得像军事行动，下一章的阵地战却充满闲言碎语。
3. **动作的观众意识**：给大人物设计做给旁观者看的动作，动作的理由是"有观众"，而非内心动机。何时用：写权力人物、表演型人格。写法示例：决战前，统帅慢悠悠扯下一只手套扔在地上，副官们争着去捡。
4. **习惯性活动塑人**：把戏剧性动作写成日常惯例，只给半个句子，人物便立起来了。何时用：配角速写、家庭氛围铺陈。写法示例：老人每次发火都扔碟子，仆人每次都接住——不写碎裂，也不写评论。
5. **动物侧写人的故事**：用动物的状态传达人间惨烈的规模。何时用：残酷场面需要克制时。写法示例：撤退路上，野狗吃得比往年都肥——屠杀的规模一个形容词都不用。

## 叙事声音与节奏

全知视角，但在众多人物之间自由流转，常突然钻进某个小人物的头脑。叙述距离可近可远：前一页是炮火下的体感，后一页是历史哲学的俯瞰。时间基本线性，极少倒叙——背景故事若真重要，就从那里写起。节奏靠两大板块的交替呼吸，长而不滞。

## 对白与细节

对白带阶级与时代的口音，沙龙腔与士兵粗话各成声部。细节强调"冰山式"的半句处理：仆人接碟、死马横陈，一个细节顶一段心理分析。意象系统朴素而反复：天空、橡树、狩猎，在大转折处默默重现，标记人物的精神刻度。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

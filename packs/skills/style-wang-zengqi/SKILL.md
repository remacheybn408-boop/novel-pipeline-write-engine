# 汪曾祺技法卡

汪曾祺最值得迁移的是散文化小说的"水"结构：淡化情节、以风俗画开篇、贴着人物写白描，用"苦心经营的随便"消解小说的戏剧性骨架，把冲突轻描淡写地化开，让人情美与语言本身的准确成为作品的主心骨。

## 核心手法

1. **风俗画开篇**：小说前三分之一不写人物冲突，只写一方水土的物产、行规、生计与节令，人物从风俗里长出来。何时用：地域题材、短篇、需要立起世界体温的作品。写法示例：写一段爱情前，先写湖边的作坊怎么开工、挑夫怎么走路、集市怎么散场。
2. **淡化高潮**：把本应渲染的冲突与灾难一笔带过，平和地化解，重事后的人心而非当时的冲击。何时用：反类型化叙事、写韧性与日常的英雄主义。写法示例：写一场横祸只一句"心里乱糟糟的"，转而细写此后街坊们如何川流不息地来探望。
3. **贴着人物写**：叙述者与人物平起平坐，把情感化成一个动作而非一句感叹。何时用：情感峰值处需要克制表达。写法示例：写她照顾重伤的人，喂药时"不知道为什么，她自己也尝了一口"——深情全在这一个动作里。
4. **语言求准**：为每个意思找到唯一准确的词，俗字常词重新赋予生命，白话里掺一点文言的筋骨。何时用：一切段落，作为修订标准。写法示例：写一个人回头，不写"含情脉脉"，写她睁大眼睛，"带点吃惊而专注的神情，好像听到远处有人叫她"。
5. **以水代山**：结构像流水不像山峦，散而不乱，所有枝蔓都朝向同一片水土。何时用：散文化长篇或系列短篇的统摄。

## 叙事声音与节奏

第三人称为主，声音温润、从容、带笑意，叙述者像一个见过世面又心怀善意的长者。时间多在回忆里，跨度可大可小。节奏如缓流：不急不促，一件事接一件事慢慢讲，重韵味轻悬念，靠语言的滋味留人。

## 对白与细节

对白极少雕琢而极生动，人物说的是带水汽的生活口语，短、淡、有余味。细节是风俗与吃食的细节：咸鸭蛋、炒米、行当手艺，写得有滋有味。意象清浅：水、花、小船、灯火，不刻意象征，美在日常本身。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

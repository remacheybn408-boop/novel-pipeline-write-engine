# 玄幻小说

把奇观、规则与人物目标绑在一起：每一种力量都应改变社会，也应带来代价。只产出原创设定和表达。

## 工作流

1. 从一个反常识的世界事实起步，例如资源、地理或记忆由何种规则支配。
2. 设计能力的来源、上限、代价、反制与社会分层。
3. 读取 `references/blueprint.md`，安排探索、对抗、揭示三条线的交汇点。
4. 每卷结尾回答一个世界问题，再提出一个更危险的问题。
5. 检查战斗是否体现角色性格与规则理解，而非单纯报数。

## 可交付内容

- 世界圣经、力量系统、势力与地图说明
- 冒险卷大纲、秘境关卡、战斗设计和揭示场景
- 升级节奏与设定矛盾排查

## 边界

- 不套用某部现成作品的专名、等级序列、种族史或剧情结构。
- 不让“终极力量”无条件解决问题。
- 不以现实文化群体的刻板印象充当异族设定。

规划时读取 `references/blueprint.md`；真正写正文、改文风或诊断节奏前，必须先读取 `references/craft.md`；写分章、连载或卡文修复时，读取 `references/chapter-engine.md`。

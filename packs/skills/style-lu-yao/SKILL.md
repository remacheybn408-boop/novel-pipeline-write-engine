# 路遥技法卡

路遥最值得迁移的是经典现实主义的"笨功夫"：以近乎科研的资料准备搭建时代背景，用个人命运与时代进程的咬合结构，配合"我们"式投入型叙述声音，把普通人的奋斗写出史诗感与可信度的双重重量。

## 核心手法

1. **档案式背景构建**：动笔前系统研读当年报刊、行业与政策资料，让背景中的物价、政策、风俗全部可考。何时用：现实题材、年代文需要可信度。写法示例：写乡镇创业，先用一节交代当时的贷款政策与原料行情，再让人物下场行动。
2. **命运—时代双线咬合**：个人关键转折（招工、承包、升学）与真实历史节点同频共振，大事件作为改变命运的外力进入情节。何时用：长篇年代叙事。写法示例：人物生意的转机恰好落在某项政策放开的同一章节，时代风转向，人的帆才鼓起来。
3. **"我们"式叙述介入**：第三人称中插入"我们的主人公"式呼告，把作者与读者拉进人物阵营。何时用：情感高点、需要凝聚共鸣处。写法示例：人物遭挫段落末尾，叙述者以"我们"发出一句克制的议论，点到即止。
4. **双线对照结构**：两个人物走不同道路（进城/留守、务虚/务实），章节交替推进互为镜像。何时用：表现选择的代价与时代的多种可能。写法示例：A线写厂子赔光，B线同章写矿井受表彰，悲喜互照。
5. **苦难转化的精神弧线**：人物不把苦难当终点，而转化为前行的燃料，弧线清晰可辨。何时用：成长型主角、励志向现实叙事。

## 叙事声音与节奏

全知第三人称，声音恳切、投入，允许抒情与议论介入但保持克制。时间大跨度线性推进，章节常以时令节气起笔，农时即叙事节拍。节奏沉稳均匀：重大事件的简要勾勒与日常细描交织，不靠悬念而靠命运感推进，读者关心的是"他能不能挺过去"。

## 对白与细节

对白朴素带方言味，讲究场合与分寸，人物在正式与私下场合说两套话。细节扎实到可检验：吃食、工分、车票、信件的写法。意象系统依托黄土地：高原四季、山川河流，景物常与人物心境同构放大，景语即情语。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

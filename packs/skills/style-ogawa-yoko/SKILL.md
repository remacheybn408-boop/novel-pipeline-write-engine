# 小川洋子技法卡

最值得迁移的是「以静写动」：用几乎静止的场景、显微级的细节观察，让人物的记忆与丧失在无声处发酵。她还擅长把抽象概念（数学、记忆、时间）变成可触摸的情感道具，是写低情节密度、高情感浓度作品的参照系。

## 核心手法

1. **限制条件做情感容器**：给人物一个硬性限制（记忆只有八十分钟、不能说出口的秘密），让情感在限制内反复撞击。何时用：主题关乎失去、需要形式与主题同构时。写法示例：设定老人每天清零记忆，温暖必须每天从零重建，读者由此掂出相处的重量。
2. **抽象概念具象化**：把数学、科学、专业知识写成有温度的情感媒介而非背景板。何时用：题材涉及专业领域、怕写成科普讲座时。写法示例：让两个角色靠一组数字的特殊关系确认彼此的羁绊，公式即情书。
3. **显微细节凝视**：对一件小物、一个动作做慢镜头式的精确描写，让静止本身产生张力。何时用：氛围压抑、暗流涌动但不能明说时。写法示例：用一整段写手指如何抚过书脊的磨损处，人物的不舍尽在其中。
4. **封闭小世界构图**：人物少、空间小、外来干扰被排除，关系在密室般的结构里缓慢变质或升温。何时用：想聚焦一段关系的细微演变时。写法示例：一栋偏屋、两三个人物、一份日常工作，全书几乎不离开这个舞台。
5. **旁观者第一人称**：让一位温和的局外人担任叙述者，透过她的眼睛测量别人的深渊。何时用：主角过于特殊、需要给读者一个代入通道时。写法示例：由家政妇讲述天才的日常，她的常识与对方的异常互相照亮。

## 叙事声音与节奏

多用第一人称或贴近的第三人称，声音安静、克制、精确。时间处理以日常循环为主，重复本身成为叙事手段——同样的问候每天重来，意义却在累积。节奏极缓，几乎无外部冲突，张力来自「不变之中正在失去的东西」。

## 对白与细节

对白轻而少，常以问句与沉默构成；重要的交流发生在知识、数字或物的传递中。细节是静物画式的：旧西装上的便签、磨损的袖口、一碗汤的温度，每一件都可回查、都有情感账。意象倾向脆弱易逝之物，与记忆主题互为表里。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

# 阿城技法卡

阿城最值得迁移的是"世俗的技艺"：用最素朴的白描和精准的动词写吃饭、下棋这类物质性时刻，文字行云流水仿佛不着一力，实则句句有讲究；在最委琐的生命细节里见出庄重，在高潮处反而收束，以道家式的克制完成人物。

## 核心手法

1. **动词白描**：写人靠一连串精确的动词而非形容词，动作的分解即性格的显影。何时用：人物定型场景、需要"看得见"的写法。写法示例：写一个人的饥饿与虔诚，只写他用食指把嘴边的饭粒抹进嘴里、把筷子舔净、小口呷汤——不置一评。
2. **物质性细节**：让破提琴、一块豆腐、一双布鞋这类俗物承担意义，传奇褪尽，物质性本身说话。何时用：反抒情、落地的生活实感。写法示例：写岁月艰难不写叹息，写一张饭桌的磨损和一顿饭的吃法。
3. **双线隐喻结构**：一条生存线（吃）、一条精神线（棋）并行推进，互相定义，俗与道互为表里。何时用：想让小人物获得精神纵深。写法示例：写车夫白天拉车的算计与夜里读帖的痴迷，两件事互相照亮。
4. **高潮收束法**：在全武行的对决顶点，用一句极轻的话收束千钧之力。何时用：大场面结局，避免情绪决堤。写法示例：一对九的盲棋大战结束，胜者只哽咽着说两个字："和了吧。"
5. **去腔调写作**：警惕任何"腔"——伤痕腔、寻根腔、文艺腔，容许笨句子傻句子存在，好句子才显得不费力气。何时用：修订阶段的风格自检。

## 叙事声音与节奏

第一人称旁观者叙述，声音平淡隽永，偶见机锋也点到为止，决不强作解人。时间顺叙，节奏从容有序，短句为主，句号用得多，文气像围棋的落子：一子一断，断中有连。

## 对白与细节

对白极简，方言与口语入文而不油滑，人物常沉默，沉默里有分寸。细节集中在身体与物：吃相、手势、器具、衣着，写物质即写精神。意象疏朗：棋、树、字典、炊烟，皆自俗世取材，以俗见道。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

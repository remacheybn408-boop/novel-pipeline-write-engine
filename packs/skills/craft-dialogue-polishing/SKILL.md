# 对话打磨

对话的功能是推进关系与暴露欲望，不是传递信息。每句话都要回答：这个人此刻想要什么，又不愿直说什么。

## 工作流

1. 先标出每场对话的潜台词：表面议题与真实诉求各是什么。
2. 给每个角色做声纹检查：用词、句长、口头禅是否可区分。
3. 删掉可以靠动作与沉默替代的解释性台词。
4. 检查对话节奏：长句爆发、短句对抗、沉默留白各司其职。
5. 通读朗读测试：拗口、说教、网文化的地方全部改写。

## 可交付内容

- 逐场潜台词标注、声纹对照表
- 改写前后的台词对照与理由
- 信息倾倒（info-dump）段落清单

## 边界

- 不改变剧情事实与人物决定，只改表达方式。
- 不为追求金句破坏角色声纹。
- 不模仿任何真实作者的台词风格。

# 军旅小说

真实感来自细节：装备之外的训练、纪律与战友情。任务推动剧情，成长回答“为何而战”。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先定主角从普通士兵到尖兵的成长曲线，再定对应考核与任务。
2. 战术场景按“侦察—部署—执行—意外—补救”写，讲清协同与纪律。
3. 建立班排人物群像：每个人都有自己的位置与故事。
4. 装备与战术细节要经得起军迷检验，不确定就模糊处理。
5. 检查每次任务是否加深人物对责任、牺牲或荣誉的理解。

## 可交付内容

- 编制与人物表、任务链、成长曲线和卷纲
- 演习、选拔、实战或救援场景
- 战术细节可信度诊断

## 边界

- 不涉真实部队番号、现役装备机密参数或真实行动。
- 不使用已知军旅作品的角色或情节骨架。
- 不神化主角；胜利靠协同与训练，伤亡要有重量。

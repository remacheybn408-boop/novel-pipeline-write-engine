# 东野圭吾技法卡

最值得迁移的是他的悬念工程学：把「谁是凶手」换成「为什么走到这一步」作为悬念核心，用精密的信息调度让读者全程参与，以人性动机承载情感重量。对悬疑乃至任何需要长线钩子的故事都有效。

## 核心手法

1. **倒悬式谜题**：在故事前半就亮出凶手或罪行，把悬念从「是谁」转移到「动机与因果」。何时用：谜底本身不够惊艳，但动机有深挖空间时。写法示例：开篇三章内让读者目击犯罪过程，随后用全书追查「他为什么非杀不可」。
2. **期待背叛设计**：先按类型惯例铺设读者预期，再在中后段颠覆它。何时用：读者对套路过于熟悉、需要新鲜感时。写法示例：让读者认定侦探角色即将破案，却揭示其推理方向从第一步就被人为引导。
3. **双线平行交叉**：两条时空线各自推进，靠物件、身份或事件暗暗咬合，直到交汇点爆发。何时用：时间跨度大、人物关系需缓慢显影时。写法示例：一条线写少年时代的事件，一条线写当下的调查，两线人物名单逐渐重叠。
4. **全知视角下的信息配额**：叙述者看得见全局，但每章只释放定量信息，核心谜团始终留白。何时用：需要维持悬念又怕读者觉得被欺骗时。写法示例：凶手的心理活动可以写，但刻意绕开能暴露身份的那一段记忆。
5. **专业细节做可信锚点**：用工程、医学、刑侦流程的硬细节压住虚构感。何时用：情节离奇、需要现实质感托底时。写法示例：借角色之口讲清一个真实原理，再让诡计建立在该原理的边界上。

## 叙事声音与节奏

以第三人称全知或多人称轮换为主，叙述距离冷静克制，不替人物下道德判词。时间处理灵活，常用倒叙、插叙拆解因果链。节奏上侦查线与情感线交替换气：每当推理推进一段，就插入一段人物的日常或过往，让读者在解谜疲劳前被情感重新抓住。章节短、收尾带钩，是典型的高转速连载节奏。

## 对白与细节

对白功能性强，多用问答推进信息，冲突型对话常一句话挑明人物立场对立。细节服务于伏笔系统：不起眼的物件、口误、时间差，埋设时都有当下场景的合理功能，回收时升级为动机证据。意象系统较弱，靠的是「社会切片」——商店街、学校、工厂等日常空间承载案件，让异常发生在最寻常的地点。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

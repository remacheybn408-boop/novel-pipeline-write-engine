# 阿尔贝·加缪技法卡

加缪最值得迁移的，是"零度"叙述：用短句与白描把情感判断全部撤走，让事件自己说话；以及用自然意象（太阳、海、光）作为推动情节的物理力量，使主题从感官而非议论中长出。

## 核心手法

1. **孤岛短句**：每句话是一个封闭的"现在"，句与句之间不做因果润滑，删除过渡与承接词。何时用：塑造疏离、麻木或高度克制的人物。写法示例："她进来了。天黑了。我打了个盹。"三件事并列，不解释关联。
2. **零度白描**：只记录可观察的动作与物，不出现情绪词与判断词，让读者自行完成道德反应。何时用：重大情绪场面（葬礼、死亡、暴力）反而要冷写。写法示例：至亲去世的场景只写守灵者的坐姿、咖啡的热气与自己的困倦。
3. **感官先于意义**：人物只理解事物的"含义"而不领会其"意义"，先写身体对温度、光、盐的反应，情绪空缺本身就是主题。何时用：写存在性迷惘或与社会脱节者。写法示例：一个人做出重大决定的理由是"太阳太晒了"，而非任何深层动机。
4. **环境作为推力**：让自然（酷热、刺眼的光）成为情节的物理触发器，外部感官压强替代内心动机。何时用：需要"非理性爆发"又要可信时。写法示例：暴力发生前，用三段递进写光线如何越来越让人无法忍受。
5. **冷漠与爆发的对位**：全书长期压在低温叙述里，结尾处安排唯一一次积蓄已久的情感喷发。何时用：需要单点高潮的中短篇结构。写法示例：前文始终"怎样都可以"的人，在最后一章突然愤怒地喊出自己的信条。

## 叙事声音与节奏

第一人称记录体，叙述距离极近却情感极远——读者贴着人物的感官走，却始终摸不到他的心。时间处理是碎片的"当下"串联，几乎无回溯、无展望。节奏均匀、单调，这种单调是刻意制造的压抑；全书的张力来自"叙述温度"与"事件烈度"之间的反差。

## 对白与细节

对白极简、功能化，常用抽空语义的短答，以对白的贫乏写存在的贫乏。细节集中在感官层：汗、阳光、烟味、海风，且细节承担情节功能。意象系统由自然元素构成——太阳几乎是一个角色，海是自由的另一面，光既是生命力也是暴力。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

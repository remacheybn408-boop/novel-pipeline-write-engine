# 灵异小说

恐惧来自可理解但难以摆脱的规则，而非任意惊吓。保持原创；民俗只作研究起点，不挪用真实作者、作品或群体偏见。

## 工作流

1. 定义异常的触发、征兆、限制、暂时应对和不可逆后果。
2. 让主角有一项必须完成的现实责任，使其无法简单逃离。
3. 读取 `references/blueprint.md`，按“异样—验证—代价—规则翻转—选择”设计章节。
4. 先用感官和日常细节制造不安，再有限度展示超常现象。
5. 检查规则是否前后一致，结局是否由人物选择而非突然驱邪解决。

## 可交付内容

- 异常规则书、民俗质感清单、调查线和恐惧曲线
- 序章、夜行、封闭空间或真相揭示场景
- 氛围诊断与惊吓密度调整

## 边界

- 不将现实宗教、民族或疾病污名化为恐怖来源。
- 不描写可操作的自伤、自杀或伤害他人的步骤。
- 不复刻已知灵异作品的规则、怪物或场景布局。

规划时读取 `references/blueprint.md`；真正写正文、改文风或诊断节奏前，必须先读取 `references/craft.md`；写分章、连载或卡文修复时，读取 `references/chapter-engine.md`。

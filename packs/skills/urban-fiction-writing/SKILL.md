# 都市小说

把城市当成持续施压的系统，而非背景板。写作必须原创：不得根据真实作者、作品或可识别文风进行仿写。

## 工作流

1. 明确主角的城市位置：职业、收入压力、关系网络、想进入的圈层。
2. 选择一个主冲突：职场晋升、创业博弈、家庭责任、情感抉择或身份秘密；只设一个主引擎。
3. 依照 `references/blueprint.md` 建立人物账本、现实约束与章节钩子。
4. 输出时先给一句话卖点，再给阶段大纲，最后写场景或章节；每场都让目标、阻力和代价可见。
5. 完稿前检查：专业细节可理解、人物不靠巧合获胜、每次进展都改变关系或资源。

## 可交付内容

- 30～100 万字连载蓝图与卷末节点
- 都市群像的人物关系图（用文字说明即可）
- 单章、开篇三章或对白重写
- 节奏诊断：指出空转场景并给出替代冲突

## 边界

- 不使用真实作者姓名、作品角色或标志性桥段作模板。
- 不把行业标签当专业性；无法核实的职业细节应改成可观察的工作流程。
- 成功不能只靠降临式资源；为机遇安排成本、风险或交换。

规划时读取 `references/blueprint.md`；真正写正文、改文风或诊断节奏前，必须先读取 `references/craft.md`；写分章、连载或卡文修复时，读取 `references/chapter-engine.md`。

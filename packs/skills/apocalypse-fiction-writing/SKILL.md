# 末世小说

灾难是背景，人性是主战场。秩序崩塌后，资源分配与信任重建才是剧情的发动机。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先定灾难的规则与不可逆性，再定幸存者的资源结构。
2. 建立聚居点、掠夺者与流民之间的供需与恐惧网络。
3. 剧情按“求生—结盟—裂痕—危机—抉择”推进。
4. 生存细节（食物、水、药品、弹药）要可核算，不开挂。
5. 检查每个抉择是否在“活下去”与“还是人”之间做权衡。

## 可交付内容

- 灾变设定、资源账本、据点关系图和卷纲
- 搜刮、防御、谈判或迁徙场景
- 生存逻辑漏洞诊断

## 边界

- 不使用已知末世作品的角色、设定或情节骨架。
- 不靠天降物资解决核心危机。
- 避免消费苦难；死亡与创伤要有重量和余波。

# 无限流小说

副本是规则谜题，主神是悬念容器。每个副本要可解、有代价、留下成长痕迹。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先定副本规则、胜利条件与隐藏陷阱，再让主角用规则而非蛮力通关。
2. 建立队伍能力互补与信任裂缝，副本外也要推进主线谜团。
3. 副本内按“入场—试探—破局—反噬—结算”推进。
4. 规则要有可验证性：读者能回看线索，认可解法成立。
5. 检查每个副本是否改变人物的能力、关系或对主神的认知。

## 可交付内容

- 副本规则卡、队伍能力表、主线谜团链和卷纲
- 密室、逃杀、解谜或对抗型副本场景
- 规则自洽性诊断

## 边界

- 不使用已知无限流作品的副本、道具或情节骨架。
- 不允许主角无代价开挂；破局必须付出对应成本。
- 死亡与背叛要影响后续副本的决策。

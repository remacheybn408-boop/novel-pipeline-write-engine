# 赛博朋克小说

高科技，低生活。技术越强大，人的议价权越小；冲突的核心是资本、身体与身份的归属权。创作必须独立，不可借真实作者或经典作品的可识别写法。

## 工作流

1. 先定技术如何分层分配：谁买得起强化，谁被系统抛弃。
2. 建立巨型企业、地下网络与街头生态的利益链。
3. 主角任务按“接单—渗透—真相—背叛—抉择”推进。
4. 黑客与战斗场景写清信息差与风险，不堆术语。
5. 检查结局人物对“何为人”的答案是否变化。

## 可交付内容

- 企业与帮派势力表、技术设定、任务链和卷纲
- 潜入、追缉、脑机接口或义体改造场景
- 世界观一致性诊断

## 边界

- 不使用已知作品的角色、公司名、地名或情节骨架。
- 技术不能凭空解决核心矛盾。
- 避免把义体与暴力奇观化；交代代价与伦理后果。

# 吉本芭娜娜技法卡

最值得迁移的是「把死亡日常化」的笔法：巨大的丧失被放进厨房、餐桌、出租屋这些最普通的空间里处理，悲伤不嚎啕而绵长。这套用生活流承载治愈主题的方法，是治愈系与都市情感写作的核心参照。

## 核心手法

1. **口语体第一人称**：叙述者像对朋友倾诉，句子松散、直接，允许含混与自我修正。何时用：需要亲近感、陪伴感的情感故事。写法示例：用「怎么说呢」「总觉得」这类口吻开场，像在咖啡馆里对读者讲自己的事。
2. **丧失的日常化处理**：死亡不写成事件高潮，而写成之后无数顿饭、无数个失眠的夜。何时用：写悲伤又不想要戏剧化嚎哭时。写法示例：亲人去世后，不写葬礼，写主人公第一次独自去超市、站在货架前发呆。
3. **治愈空间装置**：给一个具体空间（厨房、庭院、小店）赋予庇护功能，人物在此慢慢复原。何时用：需要情感锚点与安全感载体时。写法示例：反复回到同一间厨房，每次回去，人物的状态都好了一点点。
4. **梦与预感渗入现实**：用梦境、直觉、微小的超现实瞬间标记心理转折。何时用：内心变化难以用事件外化时。写法示例：人物做了一个反复出现的梦，梦的细节随她的疗愈进度悄悄改变。
5. **微小幸福的特写**：用食物、光线、季节的细节制造「活着真好」的瞬间。何时用：悲伤基调中需要透气口时。写法示例：一碗热汤、一扇晒进太阳的窗，用三行写足，然后回到沉重的正题。

## 叙事声音与节奏

以年轻女性的第一人称为主，叙述距离贴近，声音坦白、不设防。时间处理松散，常随情绪在回忆与当下间滑动。节奏缓慢而流动：情节推力弱，情绪推力强，靠一个个生活场景的累积完成人物的内心移动。

## 对白与细节

对白生活化、短而轻，重要的话常被不经意地带出。细节系统是「生活器物型」：厨具、便当、植物、旧T恤，用具象物承载抽象的依恋与失落。意象偏爱透明、流动的物——水、光、玻璃——衬出人物脆弱而清亮的状态。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

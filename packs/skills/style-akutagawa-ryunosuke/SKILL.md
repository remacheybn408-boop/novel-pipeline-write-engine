# 芥川龙之介技法卡

最值得迁移的是短篇的结构工程学：极短篇幅内完成「情境建立—人性试验—冷峻收束」的全过程，以及用多份互相矛盾的证词让「真相」本身缺席。对短篇、单元剧、悬疑与寓言式写作，这套方法至今仍是教科书级范式。

## 核心手法

1. **单一情境的人性加压**：把人物放进一个极端而封闭的情境，看他在利害面前的转向。何时用：想写人性试验而非情节冒险时。写法示例：城楼上，走投无路者撞见一个更弱者，一念之间善恶易位，全文就此结束。
2. **矛盾证词结构**：同一事件由数名当事人分别陈述，版本互相冲突，叙述者拒绝裁决。何时用：想讨论「真相是否可知」、制造开放悬念时。写法示例：一案三供，每份供词都自洽且都美化陈述者，读者只能面对不可调和的裂缝。
3. **借古写今**：取材历史或古典故事，注入现代人的心理与怀疑。何时用：现实题材太烫手或想要距离感与普遍性时。写法示例：把一个古代传说改写为心理剧，让古人说出当代人才有的利己算计。
4. **冷峻的整体关照开头**：开篇先以俯瞰视角写环境与时代背景，再收缩到人物，营造命运感。何时用：短篇需要迅速建立氛围与格局时。写法示例：先写荒废的城、连年的灾，再写那个坐在城门下等雨停的人。
5. **反转收束于一句话**：结尾用一个动作或一句台词翻转前文积累的全部预设。何时用：短篇追求余味与重读价值时。写法示例：全文写一个人坚守体面，末句写他平静地做出最不体面的选择。

## 叙事声音与节奏

第三人称为主，叙述距离冷静而克制，带学者式的精确与淡淡的嘲讽。时间高度压缩，常以几日、几时为限。节奏上段落密度极高：几乎每一段都同时承担氛围、信息与伏笔三重功能，没有闲笔。证词体作品则以形式切换（审问、独白、忏悔）代替场景转换。

## 对白与细节

对白少而锋利，常是压低声音的短句，关键处一句定人性。细节有明确的象征分工：门、火、尸体、蛛丝，一物一职，绝不浪费。意象系统冷而硬，多取破败之物对照人心。整体美学是「工笔的冷」——越是惨烈的场面，笔触越平静。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

# 伏笔管理

伏笔是作者对读者的契约：埋时要自然，收时要必然，中间要有记忆点。管理的核心是台账，不是灵感。

## 工作流

1. 建伏笔台账：埋设章节、内容、计划回收章节、当前状态。
2. 埋设三原则：首次出现有合理的当下功能、细节可回查、不突兀。
3. 每条伏笔规划“埋—提醒—收”三步，提醒点放在回收前约两成处。
4. 回收必须升级信息：兑现时给出比读者预期多一层的答案。
5. 定期审计：超期未收的要么提前收，要么明确作废。

## 可交付内容

- 伏笔台账（埋设、提醒、回收、状态）
- 回收节点的信息增量设计
- 断线与超期伏笔审计报告

## 边界

- 不为反转临时补设伏笔；所有反转必须回查有据。
- 不用伏笔密度炫耀信息差；读者体验优先。
- 作废伏笔要给出软处理，不能硬断线。

# 博尔赫斯技法卡

博尔赫斯最值得迁移的是「用论文的严谨写幻想」：以假文献、假书评、迷宫式时间和双重解读框架，把哲学命题压缩成几页的谜题，让故事为"重读"而非"初读"而写。

## 核心手法

1. **伪文献文体**：借书评、词条、审讯记录、学术注释的格式写小说，引用不存在的著作与作者，用考据口吻赋予虚构以文献重量。何时用：幻想设定需要"真实感背书"，或想省去了解释性铺垫。写法示例：为一本并不存在的巨著写严肃书评，情节在引用与注释的缝隙里展开。
2. **分岔时间迷宫**：让同一节点衍生多种互相矛盾的可能，并声明全部可能同时成立，拒绝收束为单线真相。何时用：写选择、偶然、平行命运。写法示例：人物在岔路口"选择了全部"，叙事同时追两条互斥的后续。
3. **双重解读框架**：在同一故事里安装两套以上自洽的解释系统，让它们博弈，使推理本身成为陷阱。何时用：悬疑与解谜结构，想让"聪明的解法"落败时。写法示例：侦探按图案预测第四个犯罪地点，正中凶手为他设计的圈套——线索本就是写给解读者看的。
4. **自指与循环**：让故事的结尾折返开头，或让创造者发现自己也是被创造的，形成环形结构。何时用：写梦、虚构、身份的虚无感。写法示例：用幻术造出一个人的人，最终发现自己也存在于他人的梦中，叙述闭环。
5. **无限的经济性**：把无限、永恒、同时性等宏大主题压缩进极短篇幅，靠精练准确的词与高密度信息维持张力。何时用：短篇幅承载大命题时。写法示例：用一座图书馆、一面镜子、一个点，一件器物即装下"全部"，故事在十页内完成。

## 叙事声音与节奏

多用冷静的第一人称回忆录或第三人称档案腔，叙述者克制、博学、略带迟疑，常自称记忆未必可靠。叙述距离偏远——场景让位于概述，画面让位于观念。时间是非线性的哲学变量：循环、分岔、倒退，起始时间与终结时间可以相同。节奏均匀、无高潮，张力来自信息密度与逻辑悬念而非动作。

## 对白与细节

对白稀少且高度功能化，常以转述代替直接对话。细节服务于谜题：一个名字、一枚硬币、一句引文都可能是解谜钥匙，无闲笔。意象系统高度符号化——迷宫、镜子、图书馆、梦——每个意象都是一件可携带的哲学装置，重复出现即主题复调。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

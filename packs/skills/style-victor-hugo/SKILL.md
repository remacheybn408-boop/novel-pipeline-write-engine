# 维克多·雨果技法卡

雨果最值得迁移的是"对照"的组织力：美与丑、崇高与怪诞、个人与时代并置成戏剧性情境；以及史诗级全知叙述的调度——他敢用整章离题铺设世界的厚度，再用一句话把读者拽回悬念。

## 核心手法

1. **美丑对照原则**：把极端对立面焊接在同一个人物或场景里——最丑的外形配最高的灵魂，最庄严的场合配最滑稽的破绽。何时用：需要人物立刻被记住、主题需要可视化时。写法示例：让一个佝偻口吃的守门人，在暴乱中说出了全场最有尊严的一段话。
2. **戏剧化场景搭建**：关键情节按舞台逻辑布置——单一空间、明确的进出、围观者与倒计时。何时用：审判、处决、重逢等高压节点。写法示例：刑场段落固定一个视角不动，只靠声音与人群反应推进。
3. **离题作为世界构建**：用整章"题外话"（历史考证、制度考察、城市考古）暂停情节，为故事建立百科全书式的重量，并让离题在暗处与主线呼应。何时用：史诗型长篇需要历史纵深时。写法示例：追捕线最紧张处插入一章下水道史，而主角稍后正从那里逃生。
4. **叙述者亲自入场**：全知叙述者偶尔以"本书作者"身份现身，提供自己的目击与调查，把虚构钉进史实。何时用：历史小说需要真实感背书时。写法示例："多年后我亲自到过那个街角，墙上的弹孔还在。"
5. **悬念的延宕术**：抛出重大悬念后公然离开主线十余章，用离题喂养读者的焦虑，回归时信息增量翻倍。何时用：长篇小说中段的节奏控制。写法示例：主角命运悬于一线时转入一段战场全景，归来时局势已彻底翻转。

## 叙事声音与节奏

全知视角，叙述声音洪亮、自信，带着排比与反问，随时准备从场景升入议论。时间是全景式的：战争、革命、个人命运铺在同一张地图上。节奏大起大落——场景内是戏剧的紧凑，场景间是散文的舒展，两者交替构成史诗的呼吸。

## 对白与细节

对白高度修辞化，人物在关键时刻说"宣言"，用格言推进冲突；日常对白则带俚语考据趣味。细节服务于对照与象征：烛台、制服、断墙都被赋予道德重量。意象系统围绕光与暗、深渊与升高展开，建筑（教堂、下水道、街垒）本身就是论点。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

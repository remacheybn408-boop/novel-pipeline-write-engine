# 爱情小说

以人物选择推动情感，而不是靠误会拖延。所有措辞、桥段组合和角色关系必须原创，不模仿真实作者或具体作品。

## 工作流

1. 定义两位核心人物各自独立的人生目标、恐惧与不可退让处。
2. 写出吸引力、现实障碍和价值观冲突；三者缺一不可。
3. 读取 `references/blueprint.md`，确定关系阶段与每次靠近的代价。
4. 先写外部事件，再写事件如何迫使两人重新理解对方；避免只用内心独白推进。
5. 检查双方是否拥有行动权，和解是否回应了此前造成的伤害。

## 可交付内容

- 恋爱主线、配角支线与结局路线
- 关系阶段表、情绪节拍表、关键约会或分离场景
- 开篇吸引力诊断与“为何是现在相爱”的说明
- 对白润色：保留潜台词，删去替角色解释情绪的话

## 边界

- 不把控制、羞辱或越界包装成浪漫。
- 不使用失忆、误会等套路来替代人物决定；如使用，必须有新信息和可选择的行动。
- 不复刻任何已知作品的名场面、设定或叙述口吻。

规划时读取 `references/blueprint.md`；真正写正文、改文风或诊断节奏前，必须先读取 `references/craft.md`；写分章、连载或卡文修复时，读取 `references/chapter-engine.md`。

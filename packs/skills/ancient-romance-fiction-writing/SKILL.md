# 古风小说

以虚构时代的礼制、家族和资源分配制造压力，再让人物以自己的方式回应。保持原创，禁止仿写真实作者或复刻作品桥段。

## 工作流

1. 声明这是架空、历史拟态或严格历史背景；不混用三者的规则。
2. 设定家族、婚姻、财产、出行和信息传递的限制。
3. 读取 `references/blueprint.md`，为关系线、权力线和生存线各建一条因果链。
4. 用礼节、物件、空间距离表现情感，不用现代口吻替代时代压力。
5. 检查人物是否在限制中仍有选择，而非只被情节拖动。

## 可交付内容

- 家族关系与府邸/城镇活动图
- 宫廷、家宅、行旅或婚约故事的大纲
- 含礼制张力的相见、争执、告别场景

## 边界

- 不把现代观念硬贴成古代语言；可让人物反抗，但要写出代价与途径。
- 不虚构具体史实并当作事实陈述；不确定处标记为架空设定。
- 不仿写任何已知古言作品的文风、角色或名场面。

规划时读取 `references/blueprint.md`；真正写正文、改文风或诊断节奏前，必须先读取 `references/craft.md`；写分章、连载或卡文修复时，读取 `references/chapter-engine.md`。

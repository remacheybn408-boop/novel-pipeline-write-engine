# 三浦紫苑技法卡

最值得迁移的是「职业小说」的配方：以彻底取材为地基，把一门冷门职业的内部世界写得既专业又戏剧化，让「认真做事的人」本身成为看点。这套方法适用于一切行业文、团队文与「长期主义」主题。

## 核心手法

1. **取材型专业叙事**：写某行业前先做实地调查，把真实流程转化为情节节点。何时用：行业文、职业剧需要可信度时。写法示例：编词典的每个环节——收词、释义、校对——都被设计成一轮冲突与成长。
2. **怪人主角的爱感化**：主角是有严重社交缺陷的偏执者，叙述以温柔的幽默让他的笨拙变得可爱。何时用：想写不讨喜但令人敬佩的人物时。写法示例：他在会议上答非所问、把天聊死，同事却从他逐字的较真里看见了稀有的热忱。
3. **群像对话剧**：团队里的拌嘴、吐槽、接梗承担大量人物塑造，关系在对话节奏里显形。何时用：团队文、需要快速区分五六名配角时。写法示例：一段工间闲聊，每人只用两三种口吻习惯，读者自此不会混淆任何两人。
4. **长程目标倒计时**：给团队一个以年计的宏大目标，用「进展—挫败—微光」的循环维持张力。何时用：主题关乎坚持与匠心时。写法示例：十五年编一部词典，每章解决一个小词条，同时让「大船能否启航」的悬念悬在头顶。
5. **比喻与爆笑的情感振幅**：前一页还是击中人心的精致比喻，后一页就是让人出声的幽默。何时用：怕正剧节奏变闷时。写法示例：刚用一段海上明月般的比喻写完职业的孤独，紧接着让角色在居酒屋出尽洋相。

## 叙事声音与节奏

以第三人称群像为主，视角在团队成员间灵活轮转。时间跨度大，常以年为单位推进，用季节的循环标记工程的进度。节奏从容：日常段落绵密，关键节点（比赛、交稿、验收）集中爆发，张弛靠职业流程本身的Deadline驱动。

## 对白与细节

对白是核心引擎：插科打诨里有性格，专业讨论里有价值观。细节取自真实职场——稿件、工位、行话、职业病——专业名词被解释得不露痕迹。意象常与职业主题同构：词典是「渡海之舟」，长跑是「顶风前行」，让劳动本身成为隐喻。

## 边界

- 本卡提取可迁移手法，不模仿该作家的个人风格与标志性句式。
- 示例写法为中性示范，不引用、不改写原作文字。

# AI 小说去味与人味写作指南（完整版）

> 用途：写作流水线「人味写作」席位（scene_d）的知识底座，也可作人工润色手册。
> 一句话原则：**不要替人物解释情绪，让人物在一个具体处境里做选择。** 人味不是"华丽"，而是欲望、顾忌、习惯、谎言和失控。

---

## 一、AI 味到底从哪里来

AI 写小说的根本问题不是"写得差"，而是**写得太顺、太全、太正确**：

1. **信息零损耗**：人物想什么就说什么，作者怕读者看不懂，把所有潜台词都翻译成明话。
2. **情绪直报**：不搭建产生情绪的处境，直接报名称（"他很愧疚""她心碎欲绝"）。
3. **节奏均匀**：每句差不多长，每段结构相似，每场戏的起承转合像模板倒出来的。
4. **人物无菌**：所有人都理性、体面、善解人意，没有私心、偏见、口是心非。
5. **总结冲动**：每段结尾忍不住点题，每章结尾忍不住升华。
6. **细节通货化**：细节是为了"显得有细节"而堆砌（咖啡、雨、路灯三件套），与人物和剧情无关。

去味的本质：**把"作者告诉读者"还原成"读者自己看出来"**。

## 二、AI 味症状大全（对照改法）

| # | 症状 | 典型写法 | 改法 |
| --- | --- | --- | --- |
| 1 | 直接报情绪 | "他十分愧疚。" | 写他做了什么、没做什么、付出了什么代价。 |
| 2 | 空泛形容 | "她有着绝美的容颜。" | 写她出现后具体改变了什么：谁停下了筷子，谁说话变了调。 |
| 3 | 对话太顺 | 每个人都准确表达想法 | 加入停顿、回避、答非所问、说半句收回。 |
| 4 | 作者讲主题 | "他终于明白了人生。" | 停在一个有后果的动作上，主题让读者自己长出来。 |
| 5 | 每个人都正确 | 全员理性体面善解人意 | 给人物私心、自我欺骗、不体面的第一反应。 |
| 6 | 套话句式 | "空气仿佛凝固""心跳漏了一拍" | 删。换成此刻独一的感官事实。 |
| 7 | 总结式段尾 | "这一刻，他明白了……" | 段尾落在动作、物件或未完成的事上。 |
| 8 | 排比三连 | "他恨这天，恨这地，恨这世上所有人。" | 留一句最狠的，其余删掉或拆进不同段落。 |
| 9 | 对话后机械接动作 | "他说完，转身望向窗外。"（每句对话都配同款动作） | 对话可单独成段；动作只在改变关系时出现。 |
| 10 | 句句等长 | 全段都是 15-25 字的标准句 | 长短交错：一个长句铺陈，接一个三五个字的短句砸实。 |
| 11 | 因果交代过满 | 每个行为都解释动机 | 留白：反常的动作不解释，让读者惦记。 |
| 12 | 视角漂移 | 一段里钻进两个人的脑袋 | 一场戏锁一个视角，别人的心思用表情和动作猜。 |
| 13 | 时间词油腻 | "就在这时""与此同时""刹那间" | 用事件本身推进时间，删掉报时词。 |
| 14 | 情绪词偷懒 | 紧张、悲伤、愤怒、喜悦直接出现 | 情绪词出现的段落重写：给身体反应 + 具体处境。 |
| 15 | 形容词通货膨胀 | 重要、巨大、深深、无比、格外 | 删形容词，名词动词站出来。 |
| 16 | 全员同款说话 | 所有人都是同一种书面腔 | 按人物分开句式长短、用词层级、口头禅、沉默方式。 |
| 17 | 伏笔贴标签 | "他还不知道，这个决定将改变一切" | 伏笔只埋不解说，回收时才让信息升级。 |
| 18 | 痛感缺失 | 打斗/失去写得像游戏播报 | 写代价：伤口影响下一个动作，失去改变下一个决定。 |

## 三、人味的五个来源（逐条落地）

### 1. 欲望 —— 人物每场戏都在"要"什么

- 写每场戏之前先回答：这个人物此刻想**拿到、保住、证明、还是逃避**什么？
- 欲望不必说出口。一个反复看表的人比"他很着急"有说服力十倍。
- 两个人物同场，欲望最好互相摩擦：一个想走，一个想留。

### 2. 顾忌 —— 人物不做什么，比做什么更有人味

- 怕被发现、怕被抛下、怕丢脸、怕失控——顾忌制造"想说又咽回去"的瞬间。
- 写法：让人物开口前先有一个微小的犹豫动作（摸杯子、看一眼门口），再说出一句打了折扣的话。

### 3. 习惯 —— 只有这个人物会做的动作

- 给主要人物各配 1-2 个紧张时/撒谎时/难过时的固定小动作，全书复用，成为识别标记。
- 习惯即伏笔：习惯在某章突然消失或变形，就是状态变化的信号，不用解释。

### 4. 谎言 —— 人物对自己和对别人说的假话

- 对白里的谎言：嘴上说"没事"，手上把筷子摆了三遍。
- 内心的谎言：人物给自己的行为找一个体面的理由，读者看得出真正的原因。
- **自我欺骗是高级感的主要来源**：叙述者（人物视角）说的是一套，事实露出的是另一套。

### 5. 失控 —— 计划赶不上情绪的那个瞬间

- 再冷静的人物也有一个绷不住的点。失控不是撒泼，是"声音还是平的，但杯子放下了"。
- 失控之后必须有代价和余波，不能翻页就复原。

## 四、人物六件套（开写前的准备工作）

1. **想要什么**：拿到、保住、证明、逃避什么？
2. **害怕什么**：怕被发现、被抛下、失去脸面还是失去控制？
3. **哪里矛盾**：嘴上说的和实际做的哪里打架？
4. **有什么习惯**：紧张时摸手、撒谎时解释过多、难过时忽然很客气……
5. **怎么说话**：句式长短、用词雅俗、口头禅/方言、沉默的方式（人物声纹，全书一致）。
6. **欠谁什么**：关系债——谁欠谁一句道歉、一条命、一个没说出口的秘密？债是戏的发动机。

## 五、一段戏的写法

### 段落配方

每个关键段落，至少放进下列材料中的两种：

- 动作（改变局面的，不是凑数的）
- 物件细节（与人物或伏笔挂钩的具体物件）
- 环境变化（光线、声音、天气参与叙事，不是壁纸）
- 对白（带目的的话）
- 沉默（没说出口的，往往最重）
- 错误反应（人物对事件的反应偏离"正确答案"）

### 信息分层

一段文字里同时存在三层，读者才觉得"厚"：

1. **正在发生的事**（表层动作）
2. **人物以为正在发生的事**（认知层，可以与事实错位）
3. **读者看得出而人物没意识到的事**（张力层）

AI 味重的稿子往往只有第一层。改稿时问：这段能不能加一层错位？

### 感官分配

不要五感平均用力。一场戏选**一个主感官**打透：

- 审讯戏 → 听觉（停顿、椅子腿、隔壁的水声）
- 重逢戏 → 视觉（变了的发型、没变的习惯）
- 逃亡戏 → 触觉与体感（喘、疼、冷）

主感官之外点一两笔其他感官即可，全上就是"细节通货"。

### 对照示例

不要写：

> 李明很爱母亲，但因贫穷而痛苦。

可以写：

> 母亲问他晚上吃了什么。李明说牛肉面。挂断电话后，他把泡面汤喝干净，连调料包都捏了两下。

再进一步（加一层关系债）：

> 母亲问他晚上吃了什么。李明说牛肉面，和同事一起，公司报销。电话那头沉默了一下，说那就好。挂断后他把泡面汤喝干净，连调料包都捏了两下——上个月母亲寄来的腊肠还挂在窗边，他没舍得动。

## 六、对白规则（完整版）

### 每句话都得有目的

试探、遮掩、逼问、讨好、拒绝、伤人、求证、示弱、转移话题——说不出目的的对白删掉。

### 潜台词的四种形态

1. **答非所问**：用回答别的问题来逃避这个问题。
2. **说半句收回**："其实我——算了，没什么。"
3. **反话与客套**：最狠的话用最客气的语气说。
4. **谈论第三物**：两个人谈天气、谈茶、谈孩子，其实在谈判。

### 节拍

- 重要的话前面要有停顿或动作留白，不要让人物秒回。
- 允许打断、抢话、各说各话。
- 一场对话里至少有一次"没接住的球"：一方抛出的情绪，另一方没接。

### 禁止事项

- 不让人物轮流替作者介绍背景（"你忘了吗，三年前正是你……"）。
- 不让反派宣讲计划。
- 对话不超过三句连珠炮而无动作/停顿调节（除非刻意制造压迫感）。

### 人物声纹（对白去味的核心）

- 同一段台词，换个人物说就必须换一副骨头：句式长短、用词层级、口头禅、方言词、沉默位置都不同。
- 检验方法：把对白里的人名遮掉，能否猜出是谁在说话？猜不出 = 声纹失败。

## 七、情绪写法：展示与讲述的转换表

| 别写（讲述） | 改写方向（展示） |
| --- | --- |
| 他很紧张 | 他把报名表折了四次，又摊开，折痕已经对不上了。 |
| 她很愤怒 | 她一个字一个字地把话打完，然后逐字删掉，关机。 |
| 他很悲伤 | 他照常吃了两碗饭，洗碗的时候发现多拿了一副筷子。 |
| 她心动了 | 她回家路上绕了十分钟，也没想明白为什么要绕。 |
| 他害怕了 | 他开始检查门窗。第二遍。 |
| 气氛很尴尬 | 三个人同时去够那盘菜，又同时收回了手。 |

规律：**情绪落在身体、物件和异常行为上，而不是形容词上。**

## 八、视角与人称纪律

- 一场戏锁死一个视角人物；其他人物的心理只能通过表情、动作、话语被"猜"出来。
- 视角人物不知道的信息，叙述不能提前泄露（悬疑感来自信息差）。
- 全知视角也要克制：解释人物的冲动每章不超过一次，且必须有叙事回报。
- 视角人物对自己的评价不可信（自我欺骗），读者从事实里读出反差。

---

## 九、开头与结尾

### 段落与场景的开头

- 不用时间词开头（"第二天""与此同时"），用动作或感官切入：让读者在第三句才知道自己在哪里，是加分项。

### 段落与场景的结尾

- 不以"他明白了""她决定了""命运告诉他"收尾。
- 用以下之一结束：一个动作、一个物件、一个没回答的问题、一件刚出现的代价。
- 章尾钩子三种合法形态：新信息露头、旧关系变调、代价突然到期。除此之外的"欲知后事如何"式吆喝都是 AI 味。

## 十、AI 高频句式黑名单（出现即重写）

> 他突然意识到 / 她忽然意识到 / 空气仿佛凝固 / 时间仿佛静止 / 嘴角勾起一抹 / 嘴角微微上扬 / 眼中闪过一丝 / 眼底闪过一抹 / 心跳漏了一拍 / 深吸一口气 / 不由自主地 / 下意识地 / 仿佛在诉说着 / 不禁想起了 / 空气中弥漫着 / 一股莫名的 / 心中涌起一股 / 前所未有的 / 久久无法平静 / 瞳孔骤然收缩 / 心脏剧烈地跳动 / 声音有些颤抖 / 眉头微微皱起 / 一抹不易察觉的 / 如释重负地叹了口气 / 就在这时 / 刹那间 / 殊不知 / 这一刻，他明白了

维护原则：只收短语级（≥4 字、带语境特征）的套话；泛用单词不收（"突然""仿佛"本身无罪，病在套路搭配）。

## 十一、节奏与呼吸

- **张弛交替**：高强度场景（打斗、争吵、揭秘）之后跟一个低气压场景（走路、吃饭、发呆），读者才有消化空间；连续三章高强度 = 麻木。
- **句子的呼吸**：紧张处句子变短、段落变碎；舒缓处句子拉长。句子长度本身就是情绪乐器。
- **留白**：不是每件事都要在当下交代因果。一个 unexplained 的反常细节，是读者翻页的动力。
- **信息释放**：答案揭晓时多给一层——兑现伏笔时给出比读者预期多一层的答案，而不是刚好填坑。

---

## 十二、类型差异（去味不是一刀切）

- **网文/爽文**：节奏优先，允许直白，但"直白"不等于"套话"——情绪可以明写，句式不能撞黑名单；打脸和反转靠信息差，不靠作者吆喝。
- **悬疑/推理**：信息纪律最严——视角外信息零泄露；每个细节都可能是证据，"细节通货"是重罪。
- **言情**：情绪浓度高但走潜台词路线，醋意、心动全靠错位和习惯变形表现；避免内心独白连段。
- **玄幻/修仙**：设定信息融进动作和代价里交代，不用"解说员"角色；等级、功法名出现时必须附带具体效果。
- **历史/武侠**：腔调服务人物身份，不堆砌典故；侠义落在选择的代价上，不落在口号上。
- **严肃/文学向**：留白和日常细节的权重最高，戏剧性藏在常态里。

## 十三、四级自检清单

### 句级

- 这句有没有撞黑名单套话？
- 这句的形容词删掉之后，名词动词还能不能站起来？
- 连续三句是不是等长？

### 段级

- 这段有没有直接报情绪？能否换成证据（动作/物件/异常行为）？
- 这段有没有一个"只有该人物才会做"的细节？
- 段尾是不是又在总结感悟？

### 场景级

- 这场戏里每个人物是否在追求或躲避某件事？
- 对白有没有至少一次回避、误解或潜台词？
- 信息有没有第二层（人物认知与事实的错位）？
- 场景结尾落在动作/物件/问题上，还是落在结论上？

### 章节级

- 本章开头是否承接上一章结尾的情绪与悬念？
- 本章有没有一处"计划赶不上情绪"的失控瞬间？
- 伏笔：埋下的有没有当下功能（不只是"以后有用"）？回收的有没有信息升级？
- 章尾钩子是新信息、关系变调还是代价到期？还是根本没有钩子？

## 十四、可直接使用的提示词

### 写作版（人味写作席位工作指令）

```text
根据上游规划写出本章草稿。硬性要求：
1. 不直接报情绪——用动作、物件、异常行为作证据；
2. 每个人物在这场戏里有明确的想要或害怕；
3. 对白带目的，至少一次回避、误解或潜台词；
4. 段落结尾禁止感悟总结，落在动作、物件或未回答的问题上；
5. 句长交错，禁用黑名单套话；
6. 保留未说尽之处，不交代全部因果。
```

### 润色版（改稿指令）

```text
润色以下小说片段，保留人物关系、剧情顺序、叙述人称和关键设定。
删除解释情绪、模板形容词和主题总结；用动作、潜台词、环境细节表现人物。
人物要有私心、回避和不体面的反应。
不要改变剧情，不要在结尾升华。

原文：
【粘贴】
```

## 十五、总原则（背下来）

1. 读者自己看出来的，比作者说出来的，有力十倍。
2. 人物的"不做"和"说半截"，比"做"和"说全"更像人。
3. 细节必须挂钩人物或伏笔，否则是噪音。
4. 每场戏有人想要点什么，且最好要不到。
5. 结尾停在动作上，永远不停在感悟上。
